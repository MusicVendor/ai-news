# 🧠 AI News App

An AI-powered news analysis platform that fetches real-time news, summarizes key insights, and answers user questions using RAG (Retrieval-Augmented Generation).

---

## 🚀 Features

- 📰 Fetch latest news (NewsAPI)
- ✨ AI-generated summaries (Gemini)
- ❓ Ask questions about news
- 🔍 Semantic search (RAG-based filtering)
- 🌙 Modern dark UI (React + Tailwind)
- 🌍 Fully deployed (Vercel + Render)

---

## 🏗️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios

### Backend
- FastAPI
- NewsAPI
- Gemini API

### AI Concepts
- Prompt Engineering
- RAG (Retrieval-Augmented Generation)
- Vector similarity (cosine similarity)

## ⚙️ Setup Instructions

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Environment Varibale
Create .env in backend

NEWS_API_KEY=your_key
GEMINI_API_KEY=your_key
